How to install shaders:

1. Toggle Shaders Support ON. The launcher will automatically fetch the compatible **Iris mod** (for Fabric 1.21.1 *Vanilla+*) or **Oculus mod** (for Forge packs).

2. Click Get Shaders to visit Modrinth and download a shader pack (.zip).

3. Drag & Drop the downloaded shaderpack .zip file directly into the box below (or click the box to browse).

4. Start the game, go to Options -> Video Settings -> Shader Packs, select your shader, and enjoy!
